# ACAEVAI website

10-page static brand website positioning ACAEVAI as Institutional Learning Infrastructure.

Pages: Home, Platform, Course Studio, Course Doctor, Learning Intelligence, For Institutions, Digital Academies, Learner Preview, Why ACAEVAI, Contact.

Open `index.html` directly or serve the folder with any static server. Dark mode persists with localStorage. Demo CTA and learner preview are interactive client-side.
